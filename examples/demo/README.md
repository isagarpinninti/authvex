# Demo workspace

What `authvex init` produces: three tenants (`acme_fintech_prod`, `zetechno_enterprise_sso`, `linear_ops_workspace`), five users, and `authvex.config.json`.

Every demo user's password is `demo-passphrase-1`. They are for trying Authvex locally; replace `users.json` before real use.

```bash
npx @authvex/cli studio
```

Then open the link it prints, on `http://localhost:4320`.
